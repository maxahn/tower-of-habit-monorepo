Route handlers become thin adapters. Domain rules testable through the module interface.

ADR-0001 conflict: The route handler still checks voluntaryAbsenceDaysUsed + days > 28 — the budget-based mechanic that ADR-0001 (shield-based absence) decided against. Extracting this into a module isolates the migration to one place.

Problem: The absence declaration is 60 lines of domain logic embedded in a route handler — date validation, budget arithmetic, dormancy timing, two DB writes — with no module to test independently.

Solution: An absence module with declareAbsence and cancelAbsence as the interface; the route handlers become 3-line adapters.

  • ✦ Locality: absence rules in one place
  • ✦ Route handler loses 50+ lines of business logic
  • ✦ Testable without HTTP scaffolding
  • ✦ ADR-0001 migration isolated to one module
